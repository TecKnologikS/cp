Support

Une question, un bug, un code postal erroné ? Écris à support@tecknologiks.com. Si quelque chose ne marche pas, indique ton modèle d’iPhone ou d’iPad et ta version d’iOS.

Questions fréquentes

Comment restaurer mon achat Premium ?

Ouvre l’écran Premium (touche « Sans pub » sous la bannière, ou le bouton en forme d’avion en haut à gauche de l’onglet Favoris) et touche « Restaurer les achats », avec le même compte Apple que pour l’achat. Premium se restaure aussi sur tes autres appareils connectés à ce compte.

Comment modifier ou retirer mon consentement pour les pubs ?

Sur l’écran Premium, touche « Options de confidentialité » pour rouvrir le formulaire de consentement. Le bouton n’apparaît que là où la plateforme de consentement de Google l’exige (notamment dans l’Espace économique européen, au Royaume-Uni et en Suisse). Pour désactiver le suivi publicitaire, va dans Réglages iOS → Confidentialité et sécurité → Suivi. Voir aussi « Changer tes choix » dans la politique de confidentialité.

« Autour de moi » indique Localisation désactivée

Autorise Code Postal à utiliser ta position : touche « Ouvrir les Réglages » dans l’app, ou va dans Réglages iOS → Confidentialité et sécurité → Service de localisation → Code Postal. La recherche par nom ou code postal fonctionne sans. Si ta position reste introuvable, vérifie que les services de localisation sont activés, puis réessaie.

Une commune, un code postal ou un chiffre semble faux

Les données des communes sont embarquées dans l’app à partir de sources publiques (La Poste, INSEE, API Géo) et mises à jour avec les nouvelles versions de l’app. Pour signaler une erreur, écris à support@tecknologiks.com avec le nom de la commune, son code INSEE si tu le connais, et ce que tu attendais.

Où sont mes favoris ?

Les favoris et l’historique sont stockés uniquement sur ton appareil. Ils ne sont pas synchronisés ni transférés sur un nouvel appareil.
